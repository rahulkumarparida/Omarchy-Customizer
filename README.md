# Omarchy Customizer

A local-first tool to automate and manage **Omarchy (Hyprland) customization** — including themes, configs, and UI components — through a simple web interface.

---

## 🚀 Overview

Omarchy Customizer is built to remove the repetitive manual work involved in customizing a Hyprland setup.

Instead of:
- searching GitHub repos
- copying configs
- editing files manually

You can:

> **Browse → Click → Apply**

All changes are executed locally on your system.

---

## ✨ Features (MVP)

### 🎨 Theme Management
- Apply **Omarchy themes**
- Change **Waybar styles**
- Switch **Fastfetch configs**
- Apply **Hyprlock themes**
- Use **Walker themes**

---

### 🧠 Smart Theme Collections
- Scraped and structured theme datasets
- Preview-based selection
- Organized collections for each component

---

### ⚙️ Backend Automation
- Uses existing system commands (like `omarchy-install theme`)
- Avoids breaking configs
- Safe and predictable behavior

---

### 🌐 Web Interface
- Clean dashboard UI
- Sidebar navigation for all components
- One-click theme application
- Modular design
